# Fonts

`NotoSansEthiopic-Regular.ttf` — Noto Sans Ethiopic, from the Noto fonts project
(https://github.com/notofonts/ethiopic), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Bundled so Ge'ez (Amharic) text renders in matplotlib plots and in the
Streamlit demo on machines that have no Ethiopic font (Colab, Hugging Face Spaces, most Linux).
